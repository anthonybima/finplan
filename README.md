# FinPlan — Personal Financial Planner, Analyst & Risk Manager

One React + TypeScript codebase that runs as:

| Platform | Technology | Output |
|---|---|---|
| Web / installable PWA | Vite | `dist/` (host anywhere, "Install app" in Chrome/Edge/Safari) |
| Desktop (Windows, macOS, Linux) | Electron | `release/` installer (.exe / .dmg / AppImage) |
| Mobile (Android, iOS) | Capacitor | Android Studio / Xcode project |

All data is stored **locally on the device, encrypted per user** (no server). **One account, many devices — inside Claude:** open FinPlan in Claude on each device (same Claude account). On the device that has your data: Settings → *Sync between devices* → **Turn on sync** (choose a sync password; tip: your sign-in password). On each other device: sign-in screen → **Use my account from another device** → *Find my accounts* → pick *anthonybima* → password. The encrypted copy lives in your Claude account's **private** FinPlan storage (`data/users/<you>/`, readable only by you, split into ≤180 KB encrypted pieces); no Google setup needed. **Devices for this account** (Settings): every phone / tablet / computer that opened the account, with its **Browser ID** (FP-XXXX-XXXX), platform, added and last-active dates; rename them (Phone 1, Phone 2, Computer 1…), **Remove** a device (on its next sync it erases the account from itself and signs out), or turn on **New devices need approval** (a new device waits on a *Waiting for approval* screen until an allowed device taps *Allow* on the banner). **On the website (hosted):** turn on **Google Drive sync** on your computer (Settings → *Sync between devices*), then on your phone tap **Use my account from another device** on the sign-in screen, sign in with Google, pick your account (e.g. *anthonybima*) and enter its password. The phone gets the same account (same id and name) and its data, and both stay in sync. Each FinPlan account has **its own encrypted cloud file**, so several people can use FinPlan on one Google Drive and only ever see their own data. You can also move data with *Settings → Export encrypted backup / Restore*.

**Security & hosting:** see [SECURITY.md](SECURITY.md) and [deploy/DEPLOY.md](deploy/DEPLOY.md) (Cloudflare Pages + Access recommended for personal web use).

## Features
- **Sign-in & Browser ID**: multiple local users, each with an AES-256-GCM encrypted vault (PBKDF2-SHA256 600k, non-extractable keys), recovery code, lockout after failed attempts, auto-lock on idle/background, sign-in history, and a per-install **Browser/Device ID** (`FP-XXXX-XXXX`) with environment fingerprint.
- **Markets (custom dashboard maker)**: broker-style dashboards (like Stockbit watchlists) with live tiles, sparklines, change badges and a detail view (area/line/candles, 1D–5Y, 52-week range, TradingView pro chart). Widgets: single chart, **ratio A÷B** (e.g. RSP/SPY breadth) and **watchlists**. Multiple dashboards, add/edit/reorder/resize widgets, auto-refresh 15 s–5 min. Sample dashboard: Indonesia blue chips (BBCA, BBRI, BMRI, BBNI, TLKM, ASII, GOTO, ADRO, ANTM, AMMN), USD/IDR, SGD/IDR, IHSG, QQQ, SPY, SCHD, BTC, ETH, RSP, RSP/SPY, global commodities, Asia-Pacific indices. Per-widget **data source**: **Auto = Pluang first, then TradingView** (Pluang via the Claude connector, or in the desktop app after *Sign in with Pluang*; anything Pluang doesn't cover, or any Pluang error, falls back to TradingView's live widget), Pluang only, Yahoo Finance, or **Alpaca Markets** Market Data API (US stocks/ETFs with your Alpaca key on the free IEX feed; crypto without a key). Per-widget **chart view**: FinPlan's own chart, the **TradingView** live widget, or **Investing.com**'s official live chart widget (pair ID pre-filled for gold, silver, oil, copper, gas, S&P 500, Dow, Nikkei, Hang Seng, BTC). The detail view switches between FinPlan / TradingView / Investing.com charts and links out to **AlgoBars** (which has no public chart API for personal apps).
- **Indonesian stocks (IDX)**: charts and quotes come from Pluang's IDX data (5-minute to weekly candles, last price, volume in lots, value, average price, market cap), with TradingView `IDX:` as the fallback. Add any IDX code in the widget editor. Every IDX row, holding and detail view has an **Open in Stockbit** link: Stockbit has no public API or embeddable chart, so FinPlan opens `stockbit.com/symbol/CODE` instead of scraping it.
- **Phone view**: a toggle (bottom-left) renders the app in a phone frame, handy in Claude's side panel or a desktop browser (uses container queries, so it's the real mobile layout).
- **Security center**: live checklist (encryption, HTTPS, CSP, framing, auto-lock, storage persistence, backups, privacy mode, failed sign-ins) with one-click fixes.
- **Dashboard** – net worth, monthly cash flow, savings rate, health score, budgets, net-worth trend, top advice, headlines.
- **Transactions** – manual entry, plus **CSV/Excel import** from bank & e-wallet apps (BCA, Mandiri, BRI, BNI, Jenius, Jago, GoPay, OVO, DANA, ShopeePay, Money Lover, etc.). Auto-detects the header row, column mapping, `DB/CR` suffixes, Indonesian number/date formats. Duplicates are skipped and keyword rules auto-categorise.
- **Plan & Goals** – monthly budgets (auto-suggested from history), 50/30/20 check, goals with a **Monte Carlo success probability** and the monthly saving you'd need.
- **Wealth** – bank, e-wallet, cash, investments by asset class, other assets, debts (rate + installment). **Compact** view (default, fits one phone screen): a small summary (*Net worth = assets − debt*; cash is part of assets, shown ≈ US$), one switch row (*Type / Bank / Currency* and *Compact / Cards / Table*), and one line per group with its total — tap to open its accounts (one line each); empty or not-entered accounts fold into one line (*Hide empty*); *Enter N balances* in the list toolbar; *By currency*, *Rates* and *By year* are tabs; Import, Bulk edit, Groups, Show/Hide account numbers and Connect apps sit in the ⋯ menu. **Sample data**: if the demo data (*Explore with demo data*) is mixed with your own, a banner (Wealth, Dashboard, Settings) shows what it adds and **Remove sample data** deletes only the sample accounts, positions, transactions, goals, history and budgets. **Insurance** (section in Wealth, *not counted in net worth*): policies with insurer, type (life, health, unit-link, critical illness, accident, vehicle, property, travel), policy number, insured person, coverage (sum assured, any currency), premium and how often it is paid, start year, end date, next premium due, status and notes; the header shows total active coverage and premiums per year. Kept apart from accounts, so coverage never enters net worth, totals, risk or allocation (a unit-link's fund value can still be tracked as a fund account). Imports send pure insurance rows (e.g. Chubb Life, MSIG Vega Tradisional) to Insurance; older empty insurance accounts can be moved with *Move to Insurance*. Policies sync between devices and are in Ask Claude's snapshot as protection, not wealth. **Government bonds**: a name with an SBN series (FR0090, PBS032, ORI025, SR021, ST012, SBR013; also *FR090*) makes the account an investment in *Bonds*; known series fill the coupon and **maturity date** (FR0090: 5.125%, 15 Apr 2027, from KSEI's register); bonds, deposits and loans have a maturity date shown as *matures Apr 2027 · 5 mo left*. **Cards / Table** view: the table lists every account and portfolio position with a **Since** column (year opened / first bought, typed inline; 4-digit years 1950–now, empty clears) and **Age**, plus **Interest** (% per year) and **Duration** (term / jangka waktu: 3 mo, 1 yr…). Duration and interest are set in *Edit account* (any account type) or *Bulk edit* (*Set duration*, *Set interest*), and imported from a *Tenor / Jangka waktu / Durasi* column or from the name (*Deposito … (3 bulan)*, *bunga 6.5%*). **Wealth by year opened** groups today's value (assets and debt) by that year, with share of assets; synced app accounts take the year of their oldest position and are counted per position (no double counting). Years survive app re-syncs and re-imports, sync between devices, can be imported (*Since / Sejak / Tahun buka / Tanggal beli* columns; in the templates) and are part of Ask Claude's snapshot. **Group by bank / app** (toggle *By type | By bank / app*): one card or table section per institution (Mayapada, BCA, Mandiri, Neobank, Stockbit…) with its net total, so all tabungan and deposito at one bank sit together. The group is detected from the account name (40+ Indonesian banks, digital banks, brokers, crypto exchanges, insurers) and can be changed in *Edit account* (*Bank / app*), next to the **account number** (full number, typed or imported). Cards and the table show the full number (click to copy); **Hide numbers** masks them (···9990), e.g. when sharing your screen, and is remembered. **Bulk edit**: a spreadsheet of every manual account (name, bank / app, account no., type, class, balance, interest, monthly payment, since): edit cells directly, paste a column from Excel into the first cell to fill down, filter with several names separated by commas (e.g. *mayapada, seabank, other*; *other* = accounts with no bank / app), tick rows to set group / type / since / interest / **balance** or delete many at once, add rows, then *Save changes* once (changed rows are highlighted; amounts accept 15.250.000, 15,2jt, 250rb). The *Account no.* and *Bank / app* columns are in the Excel template and in *My current data*. **Groups** (button, or the pencil on a group card): make your own group (e.g. *Mandiri* holding Mandiri RDN Growin, Rekening SGD and USD Tabungan), tick its accounts, rename it, or type an existing name to merge two groups; groups you set on synced app accounts survive re-syncs. Growin / Mandiri Sekuritas accounts are grouped under *Mandiri* automatically. **Currencies**: every account has a currency (IDR, USD, SGD, EUR, JPY, AUD, GBP, CNY, HKD, MYR, SAR), shown as a tag on each account and a *Currency* column in the table. Foreign-currency accounts keep their amount in that currency (e.g. *Mandiri USD Tabungan* US$ 12,500.50, *Rekening SGD* S$ 3,200.75) and are counted in rupiah at the current rate; changing a rate updates their rupiah value. Set it in *Edit account* (currency, amount, rate), *Bulk edit* (*Currency* column, *Set currency*) or the monthly update; imports detect it from the name or a Currency column (*USD*, *SGD*, *usd*, *$*). **Exchange rates** card: USD/IDR, SGD/IDR… with *Update rates* (live on the website / apps; inside Claude type your bank's rate). **US$ equivalent**: net worth, assets and liquid cash show ≈ US$; group totals too; **By currency** grouping and a **Wealth by currency** card (amount in each currency, rupiah, US$, share of assets; app positions in their own currency, e.g. US stocks in USD). Accounts imported without an amount show *balance not entered* and a banner opens **Enter balances**, grouped by bank.
- **Analyst** – income vs expense with a 3-month trend forecast, category trends, cumulative savings, month-over-month table, unusual-spending detection, income sources.
- **Risk** – financial health score (7 weighted ratios), risk-profile quiz with target allocation, portfolio expected return / volatility / **VaR 95 & 99 / CVaR / Sharpe / HHI concentration**, rebalancing plan, **stress tests** (market crash, crypto winter, rate hike, job loss, inflation, medical emergency), debt payoff planner (avalanche vs snowball), emergency-fund calculator.
- **Advice** – rule-based advisor (urgent / warnings / tips / positives) recalculated from your data.
- **News**: official RSS headlines from **Wall Street Journal** (Markets, Economy…), **New York Times** (Business, Economy, DealBook), **Bloomberg** (Markets, Economics…), **Investing.com** (Stock market, Commodities, Forex…), CNBC Indonesia and Google News (IHSG, BI, rupiah). Filter by publisher; pick sections in *Sources*. Headlines + publisher summaries only; articles open on the publisher's site (subscriptions may apply). Items are tagged by what they affect (rates, inflation, currency, stocks, gold, crypto, bonds…) and filterable to "for my portfolio". Sources are editable.
- **Import data: accounts + portfolio** (Wealth, Connections, Weekly review, Monthly update → *Import data*): one place to bring in **account balances** (banks, e-wallets, cash, funds/deposits/bonds/gold, property, loans and credit cards) and **portfolio positions**. Reads Excel (`.xlsx/.xls/.ods`, **every sheet**), CSV/TSV/semicolon, JSON (FinPlan holdings snapshot or any array of objects), tables pasted from Excel/Google Sheets, plain lines like `BCA  15.250.000` / `OVO: 250rb`, and screenshots/PDFs (read by Claude, accounts and holdings in one go). Each sheet is detected as accounts / portfolio / bank transactions (sent to Transactions → Import). Columns are matched in Indonesian or English (Nama Rekening, Jenis, Saldo, Bunga, Cicilan · Kode, Lot, Harga Rata-rata, Harga, Broker…) and can be changed. Review step: accounts are matched to existing ones by name (*Update “BCA Payroll”* or *New account*, with the old balance shown), type is inferred (Kartu Kredit/KPR/paylater → debt, Reksa Dana → fund, GoPay/OVO/DANA → e-wallet…), USD converted at your USD/IDR rate; synced app accounts are never overwritten. Then the portfolio review (same as Smart scan). **Account lists without balances** (e.g. *NAMA INVESTASI · NOMOR REKENING · NAMA PEMILIK · STATUS · TAHUN PEROLEHAN*) import too: account numbers are never used as amounts; the full number is kept and can be edited in the review; importing the original sheet again after a last-4-only file fills in the full numbers without duplicates (accounts are matched by account number, then name); the owner's name is removed from account names; *Tahun perolehan* becomes Since; interest in the name (*bunga 6.5%*) becomes the rate; the bank / app group is set. Rows are left unticked, with the reason shown, when they are: not *AKTIF*, owned by someone else, the same account number listed twice (e.g. RDN IPOT BCA = RDN BCA; a broker SID shared by Stockbit/Bibit/Ajaib/IPOT is not a duplicate), pure insurance without cash value (unit-link counts as a fund), a safe deposit box, or an app already tracked in Connections. After saving, **Enter balances** opens for accounts without an amount. Templates: Excel (Accounts + Portfolio + How-to sheets), accounts CSV, portfolio CSV, and **My current data (Excel)** to edit offline and re-import.
- **Smart scan portfolio import** (Connections → *Smart scan*, every broker card, and step 1 of the weekly review): scan screenshots, PDF statements or pasted text from any app (Stockbit, Pluang, Bitget, Bittime, Ajaib, IPOT, Bibit, banks…) into holdings. Three readers:
  - **Claude** — inside Claude, the page asks Claude to read the images on your own Claude account (no key).
  - **Claude API** — desktop, phone and hosted web: your own Anthropic API key (default model `claude-sonnet-5-5`), encrypted in your vault, sent only to `api.anthropic.com`. Reads images and PDFs.
  - **On-device** — pasted text only, no AI, nothing leaves the device. Understands Indonesian/US number formats, `jt`/`rb`/`K`/`M` suffixes, lots, and Stockbit-style blocks or table pastes.
  Every scan opens an editable review table (symbol, type, market, qty, lots/shares, avg, last, value, currency; IDX lots → shares ×100; missing price/avg filled from value and P/L). Save to a broker as *Update & add* (same symbols updated, others kept) or *Replace all*.
- **Connections** – one place for all investment apps; every position flows into net worth, allocation, VaR and advice:
  - **Bitget**: live sync with a *read-only* API key (spot coins + futures/earn/bots/funding balances; UTA accounts via v3). Requests are HMAC-SHA256 signed on the device. On desktop the key is encrypted with the OS keychain (Electron `safeStorage`). Keys are never in backups and never sent through a proxy.
  - **Bittime**: live sync through Bittime's Open API (`GET /api/v1/account`, Binance-style hex HMAC-SHA256 signature, `X-MBX-APIKEY` header). Coins are valued in USD (Bitget public tickers, falling back to Bittime's own ticker); the IDR balance counts as rupiah cash. Bittime has no read-only key type, so create the key with Trade and Withdraw off and IP-restricted.
  - **Alpaca Markets**: live sync via the Trading API v2 (`GET /v2/account`, `GET /v2/positions`, `APCA-API-KEY-ID` / `APCA-API-SECRET-KEY` headers). Live or paper account; option contracts are expanded to 100-share units; **paper positions are shown but excluded from net worth**.
  - **Pluang (direct MCP)**: FinPlan is an MCP client of Pluang's official server `https://mcp.pluang.com/mcp`. Desktop sign-in uses OAuth 2.1 with dynamic client registration + PKCE (S256), a loopback redirect `http://127.0.0.1:47615/callback`, refresh tokens and revocation on disconnect. FinPlan requests **only `market:read portfolio:read`** (never `trade:write`). It calls `portfolio_get_holdings` + `portfolio_get_wallet_balance` and shows a **Pluang portfolio** panel (total, unrealised P/L, Pluang-reported NAV, allocation by category, best/worst performers). **Inside Claude**, FinPlan reads the same portfolio and cash wallets through Claude's own Pluang connector (read-only tools `portfolio_get_holdings` + `portfolio_get_wallet_balance`), automatically when FinPlan opens (at most every 2 h) and with *Sync portfolio*. Mobile/web: import a `finplan-holdings` snapshot, or use **Smart scan** on a screenshot.
  - **Stockbit**: no public API. **Smart scan** a portfolio screenshot, add positions in lots, or import a CSV (template in the app); IDX prices auto-update (Pluang, or Yahoo Finance `.JK`). Each IDX holding has an **Open in Stockbit** link.
  - **TradingView**: official embeddable widgets (ticker tape of your holdings + advanced chart), import a TradingView Portfolio transactions CSV, export all holdings as a TradingView-importable CSV.
  - Live USD/IDR rate, and **Sync all** in the weekly review.
- **Ask Claude** (menu → *Ask Claude*, plus *Ask Claude* buttons on Dashboard, Analyst and Risk): a chat analyst that answers with your own numbers. Each question carries a ~15 KB snapshot built from FinPlan's calculations: balance sheet, accounts, portfolio (top 40 positions with P/L), allocation, risk model (VaR/CVaR, volatility, stress tests), health score parts, 6-month cash flow, spending this/last month, budgets, goals with Monte-Carlo odds, unusual spending, recent transactions and the app's own advice. Privacy switches remove account/goal names and transactions; *See what Claude sees* shows the exact snapshot. Never sent: passwords, API keys, account numbers. Chats live in memory only (not saved or synced). Inside Claude it uses your Claude account (streamed answers); on the website/apps it uses your own Claude API key (same encrypted key as Smart scan). Answers render as formatted text and tables (safe renderer, no HTML injection). Suggested questions in English and Indonesian.
- **Google Drive sync (one user, many devices)** — website and installed web app. Settings → *Sync between devices*. FinPlan signs in with Google in a popup that returns to its own `/oauth-google.html` (no Google script loaded into the app), with only the `drive.appdata` scope (hidden app folder; can't see other files). Data is **end-to-end encrypted** with a sync password (PBKDF2-SHA256 600k → AES-256-GCM, AAD `finplan-sync-v1`); the derived key is kept per device inside the user's encrypted vault. Syncs on open, on return to the app, and ~4 s after each change; revision numbers detect conflicts, then you choose *Combine both* (merge by id; newest account balance wins), keep this device, or use the other device. New device: sign-in screen → *Use my account from another device* (or create a user → welcome screen → *Sync from Google Drive* and pick the account). One cloud file per FinPlan account (`finplan-account-<id>.json`, labelled with the account id and name); an older single shared file is moved to the account's own file on its next sync. API keys never sync. Needs your own Google OAuth client ID (setup steps in the upload guide, section *Sync between devices*; or build with `VITE_GOOGLE_CLIENT_ID`).
- **Monthly account-update reminder** (default: **1st Sunday of every month, 09:00**): from that day a banner on Dashboard and Wealth (plus a dot in the menu) asks you to update balances until it's done. *Update now* opens one screen with every manual account (banks, e-wallets, cash, manual investments, debts) and the net-worth change; *Save & mark done* records the month. *Tomorrow* snoozes a day; ✓ marks done. It also counts as done automatically when every manual account was updated on/after the day. Settings → **Reminders**: week (1st–4th/last), weekday, time, device notification (when FinPlan is open) and **Add to my calendar (.ics)**, a repeating calendar event (`RRULE:FREQ=MONTHLY;BYDAY=1SU`) that reminds you even when FinPlan is closed.
- **Weekly review** – 4-step guided routine: update balances → import/add the week's transactions → review budgets & warnings → save a net-worth snapshot with a note. The dashboard reminds you when it's due.

## Run it
```bash
npm install
npm run dev            # web, http://localhost:5173
npm run build          # app build in dist/ (used by Electron + Capacitor)
npm run build:web      # hardened web build in dist-web/ (CSP, headers, noindex) for hosting
npm run audit          # dependency vulnerability check
```

### Desktop app
```bash
npm run electron:dev   # run as a desktop window
npm run electron:build # build installer into release/
```
News is fetched in Electron's main process, so feeds work without CORS issues.

### Mobile app
```bash
npm run cap:add:android      # once (needs Android Studio)
npm run cap:android          # build, sync and open in Android Studio → Run / Build APK
npm run cap:add:ios          # once (macOS + Xcode)
npm run cap:ios
```
`CapacitorHttp` is enabled, so RSS news is fetched natively on the phone.

## Monthly (1st Sunday)
FinPlan reminds you: **Update now** → enter each account balance → **Save & mark done** (≈5 min). Then *Sync connected apps* or *Smart scan* your portfolio.

## Weekly data routine (≈10 min)
0. Connections → **Sync all** (Bitget, Bittime, Alpaca, Pluang MCP, prices, USD/IDR).
1. In each banking / e-wallet app download this week's *mutasi* (CSV/Excel) — or the monthly e-statement.
2. Open **Weekly review** → update balances → import the files → add cash spending manually.
3. Check budgets and warnings → **Finish review** (saves a snapshot for the net-worth trend).

## Project structure
```
src/lib/      auth (accounts, vault, Browser ID), cryptoBox, secure (API keys), types, storage, importer, analytics, risk, advice, news, connectors
src/views/    Dashboard, Transactions, Plan, Wealth, Analyst, Risk, Advice, News, Weekly, Settings
electron/     hardened desktop shell (main + preload)
deploy/       DEPLOY.md, nginx + Caddy configs · security.config.cjs = single source for CSP/headers
capacitor.config.json   mobile shell config
```
Risk assumptions (return / volatility / crash per asset class) live in `src/lib/risk.ts → ASSUMPTIONS`; edit them to your own views.

*Advice and risk figures are educational estimates from long-run assumptions, not licensed financial advice.*
